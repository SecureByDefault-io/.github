# SecureByDefault

### Learn Linux, cybersecurity, cloud, and IT skills without the fake hacker drama.

SecureByDefault builds practical, beginner-friendly learning resources for people working toward careers in IT support, Linux administration, cloud, cybersecurity, and DevOps.

The focus is simple:

**Learn the concept. Practice the skill. Troubleshoot real problems. Prove what you can do.**

---

## 🚀 Start Here

### [SecureByDefault Learning Paths](https://github.com/SecureByDefault/securebydefault-learning-paths)

A free, open curriculum built around practical skills instead of random tutorials.

Choose a goal and follow a structured path:

- 🖥️ IT Support
- 🐧 Linux Administration
- ☁️ Cloud Support
- 🔐 Cybersecurity
- ⚙️ DevOps

The learning paths reuse shared foundations so you do not have to relearn the same material over and over.

---

## 🐧 Linux First

Linux is currently the deepest path in the project.

Topics include:

- Terminal navigation
- Files and directories
- Users and permissions
- Processes and services
- Logs
- SSH
- Package management
- Networking
- Troubleshooting
- Basic server security
- Hands-on projects
- Interview preparation

If you are new, start with the Linux path and build from there.
